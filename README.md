# Shaik Ahmad — Portfolio Demo

A responsive personal portfolio demo with a small rule-based portfolio assistant.

## Run locally
Open `index.html` in a modern browser. Google Fonts require an internet connection.

## Included
- Responsive one-page portfolio
- About, skills, projects, experience and contact sections
- Mobile navigation
- Demo portfolio assistant with preset answers
- Contact form that prepares an email using the visitor's email app

## Before sharing with clients
1. Replace `hello@example.com` with your real public email in `index.html`.
2. Verify every project description, status and technology list.
3. Add links to public repositories/live projects where available.
4. Replace demo project visuals with real screenshots.
5. If you want a real AI assistant, connect a backend endpoint to an AI API. Do not put API keys in browser JavaScript.
6. The assistant is currently rule-based demo behavior, not a live AI model.
7. The contact form uses `mailto:` and does not save or transmit submissions to a server.

## Deploy with GitHub Pages
1. Create a public GitHub repository, for example `shaik-portfolio`.
2. Put `index.html` and `README.md` in the repository root.
3. Run:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio demo"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/shaik-portfolio.git
   git push -u origin main
   ```
4. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
5. Wait for the Pages deployment to finish. The URL will be `https://YOUR_USERNAME.github.io/shaik-portfolio/`.

This is a portfolio demo, not a production AI integration or backend contact system.
